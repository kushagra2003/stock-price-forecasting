# Stock Price Analysis and Forecasting

This project involves time series analysis and forecasting of TCS stock prices using ARIMA models. The analysis is performed in a Jupyter Notebook with Python.

---

## Project Overview

The goal of this project is to analyze historical stock price data for Tata Consultancy Services (TCS) and build a predictive model to forecast future prices. The project includes data collection, exploratory data analysis (EDA), model building, and evaluation.

---

## Features

- Collected historical stock price data using the Yahoo Finance API
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA) including price trends and moving averages
- Built and tuned an ARIMA model for forecasting
- Model evaluation using Root Mean Squared Error (RMSE)
- Visualization of actual vs predicted stock prices
- Fully reproducible Jupyter Notebook with code and explanations

---

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Python 3.x
- Jupyter Notebook
- pandas
- numpy
- matplotlib
- statsmodels
- yfinance

You can install the required packages via pip:

```bash
pip install pandas numpy matplotlib statsmodels yfinance

Usage
	1.	Clone this repository:
git clone https://github.com/your-username/stock-price-forecasting.git](https://github.com/kushagra2003/stock-price-forecasting)

	2.	Open the notebook:
jupyter notebook stock_price_forecasting.ipynb

	3.	Follow along with the notebook to run data analysis and forecasting.\
